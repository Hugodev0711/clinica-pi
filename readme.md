1. Ideia do Projeto
A ideia inicial do projet é desenvolver um sistema para gerenciar uma clínica médica.

O sistema terá como objetivo facilitar o gerenciamento de clientes, procedimentos e agendamentos, contando inicialmente com as seguintes funcionalidades:

    Cadastro e gerenciamento de usuários;
    Cadastro e gerenciamento de procedimentos/serviços;
    Criação e gerenciamento de agendamentos;
    Visualização dos agendamentos através de um calendário;
    Alteração e cancelamento de agendamentos;
    Sistema de envio de mensagens/notificações para o cliente quando:
        Seu agendamento for confirmado;
        Seu agendamento for alterado;
        Seu agendamento for cancelado;
        O cliente não comparecer no horário agendado;
