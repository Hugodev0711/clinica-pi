1. Ideia do Projeto
A ideia inicial do projet é desenvolver um sistema para gerenciar uma clínica médica.

O sistema terá como objetivo facilitar o gerenciamento de clientes, procedimentos e agendamentos, contando inicialmente com as seguintes funcionalidades:

    Cadastro e gerenciamento de usuários;
    Cadastro e gerenciamento de procedimentos/serviços;
    Criação e gerenciamento de agendamentos;
    Visualização dos agendamentos através de um calendário;
    Alteração e cancelamento de agendamentos;
    Sistema de envio de mensagens/notificações para o cliente quando:
        Seu agendamento for confirmado;
        Seu agendamento for alterado;
        Seu agendamento for cancelado;
        O cliente não comparecer no horário agendado;

A ideia é que o sistema possua uma interface simples e fácil de
utilizar, tanto para os administradores quanto para os clientes.

2. Telas principais

Inicialmente, o sistema será dividido em duas áreas principais:

Tela administrativa

Será utilizada pelos responsáveis pelo estabelecimento.

Nela, o administrador poderá:

    Cadastrar e gerenciar procedimentos;
    Visualizar os clientes;
    Visualizar os agendamentos;
    Consultar os horários disponíveis;
    Visualizar os agendamentos através de um calendário;
    Editar ou cancelar agendamentos;
    Gerenciar outras informações necessárias para o funcionamento do estabelecimento.

Tela do cliente

Será utilizada pelos clientes para realizar e acompanhar seus
agendamentos.

Nela, o cliente poderá:

    Visualizar os serviços/procedimentos disponíveis;
    Consultar horários disponíveis;
    Realizar agendamentos;
    Visualizar seus próprios agendamentos;
    Acompanhar alterações ou cancelamentos relacionados aos seus agendamentos.

Tela não logada

Será utilizada pelo
usuário enquanto ainda não realizou o login.

Nela, o usuário poderá:

    Realizar seu cadastro;    
    Visualizar os serviços/procedimentos disponíveis;      
    Visualizar unidades disponíveis;

As funcionalidades podem ser alteradas ou adicionadas conforme o projeto
for sendo desenvolvido e conforme as orientações do professor.
